# Travescout 🧭

A travel deals scanner that aggregates prices across flights, trains, and buses.

## Stack
- Next.js + Tailwind CSS
- Flight/train/bus APIs (Skyscanner, Trainline, FlixBus)
- Mobile app in progress

## Features
- Multi-modal travel search (flights, trains, buses)
- Price comparison across providers
- QR code sharing for routes
- Mobile-friendly interface
